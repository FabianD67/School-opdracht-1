Wat is Azure?

Microsoft Azure is een cloud computing platform waarmee bedrijven applicaties kunnen bouwen, testen en beheren via datacenters van Microsoft.

Belangrijkste Diensten

Virtual Machines

Maak en beheer virtuele servers in de cloud.

Azure Storage

Veilige opslag voor bestanden, databases en back-ups.

Azure AI

Gebruik artificiële intelligentie en machine learning.

Voordelen van Cloud Computing

  • Schaalbaar
  • Veilig
  • Goedkoper dan eigen servers
  • Overal toegankelijk
